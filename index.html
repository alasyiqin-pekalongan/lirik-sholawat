Petunjuk Install AA Media di iOS

Untuk menginstal aplikasi ini, ikuti langkah-langkah berikut:

  1. Ketuk tombol Bagikan (Share) di bagian bawah layar.
  2. Pilih opsi Tambahkan ke Layar Utama (Add to Home Screen).
  3. Ikuti petunjuk untuk menyelesaikan instalasi.
CARA INSTALL, Klik Titik Tiga Di Pojok Kanan Atas, Lalu Tambahkan Ke Layar Beranda, lalu Install AA Media.
